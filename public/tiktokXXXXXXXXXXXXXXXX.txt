SFFS x TikTok - DOMAIN VERIFICATION PLACEHOLDER
================================================

This is a PLACEHOLDER. It is NOT a real TikTok verification file and does
nothing on its own. It exists to show you exactly where the real file goes.

TikTok verifies domain ownership by asking you to host a small text file at
your site root. To complete verification for smartfellaorfartsmella.com:

1. In the TikTok for Developers portal, open your app -> "URL properties"
   (a.k.a. domain / property verification) and choose "Verify via file".
2. TikTok gives you a file named like:  tiktok<code>.txt
   (for example  tiktok8f3c2a1b9d4e5f6a.txt ) containing a single line of
   verification text.
3. Save that EXACT file (exact name, exact contents) into THIS /public folder.
   Next.js serves /public at the site root, so it becomes reachable at:
      https://www.smartfellaorfartsmella.com/tiktok<code>.txt
4. Redeploy (git push to main), confirm the URL returns the file, then click
   "Verify" in the portal.
5. Delete this placeholder once verification succeeds.

Do NOT rename TikTok's file and do NOT add anything to its contents.

Note: our Direct Post flow uses FILE_UPLOAD (we push the mp4 bytes), so domain
verification is NOT required just to post. It is only needed if you later switch
to PULL_FROM_URL or add web/redirect URL properties in the portal.
